基于现代Web技术的纯静态音乐播放系统，实现无服务器全功能音乐体验。

## ✨ 核心特性
- 零服务器端依赖的PWA应用
- 浏览器内音频解码与处理
- 智能离线缓存策略
- 本地化用户数据存储
- 动态音频可视化系统
- 多格式音频支持（MP3/FLAC/OGG）

## 🚀 快速启动
### 环境要求
- Node.js 18+
- npm 9+
- FFmpeg 6+

### 安装步骤
```bash
# 克隆仓库
git clone https://github.com/your-repo/harmonic-static.git
cd harmonic-static

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
